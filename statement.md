# Problem Statement

## Title

Personal Expense Tracker using Python

## Introduction

Managing daily expenses manually can make it difficult to keep track of how much money is being spent. A simple expense tracking system can help users record their expenses and calculate the total amount spent.

## Problem

The user needs a simple program to record daily expenses and calculate the total amount spent. The program should be easy to use and should provide basic options for managing expenses.

## Proposed Solution

The Personal Expense Tracker is a menu-driven Python program. It allows the user to add expenses, view recorded expenses, calculate the total expense, and exit the program.

## Objectives

1. To create a simple expense tracking program.
2. To record the name and amount of each expense.
3. To display all recorded expenses.
4. To calculate the total amount spent.
5. To practice basic Python programming concepts.

## Functional Requirements

The program should provide the following options:

1. Add Expense
2. View Expenses
3. Total Expense
4. Exit

### Add Expense

The user enters the name of the expense and its amount. The program stores the expense in a list.

### View Expenses

The program displays all the expenses that have been added by the user.

### Total Expense

The program calculates and displays the total amount of all recorded expenses.

### Exit

The program terminates when the user selects the exit option.

## Python Concepts Used

* Variables
* Input and Output
* Lists
* Functions
* Conditional Statements
* For Loop
* While Loop
* Arithmetic Operators

## Scope

The project is designed for basic personal expense tracking. It can record multiple expenses during one program session and calculate the total amount spent.

## Limitations

1. Expenses are not permanently stored.
2. Expenses are lost when the program is closed.
3. The program does not use a database.
4. The program does not provide graphical charts.

## Future Enhancements

1. Add expense categories.
2. Store expenses permanently in a file.
3. Add monthly expense reports.
4. Add a graphical user interface.
5. Add charts for expense analysis.

## Conclusion

The Personal Expense Tracker provides a simple way to record and calculate daily expenses. The project demonstrates the use of basic Python programming concepts and helps in understanding how a menu-driven application works.
