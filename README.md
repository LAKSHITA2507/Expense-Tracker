# Personal Expense Tracker using Python

## Project Overview

The Personal Expense Tracker is a simple Python-based project used to record and manage daily expenses. It allows the user to add expenses, view all recorded expenses, and calculate the total amount spent.

## Objectives

1. To keep track of daily expenses.
2. To calculate the total amount spent.
3. To practice basic Python programming.
4. To use lists, functions, loops, and conditional statements.
5. To develop a simple menu-driven Python application.

## Features

* Add a new expense
* View all expenses
* Calculate total expenses
* Exit the program

## Technologies Used

* Python
* GitHub

## Python Concepts Used

* Variables
* Input and Output
* Lists
* Functions
* Conditional Statements
* For Loop
* While Loop
* Arithmetic Operators

## How the Program Works

The program displays a menu with different options.

1. The user can add an expense by entering the expense name and amount.
2. The user can view all recorded expenses.
3. The user can calculate the total amount spent.
4. The user can exit the program.

## Limitations

* Expenses are not permanently stored.
* All expenses are lost when the program is closed.
* The project does not use a database.
* The project is designed for basic expense tracking.

## Future Enhancements

## Conclusion

The Personal Expense Tracker is a simple Python project that demonstrates basic programming concepts such as variables, lists, functions, loops, conditional statements, and arithmetic operations. It provides a basic way to record and calculate daily expenses.
